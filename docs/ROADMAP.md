# Roadmap

## v0.1.0 — Demo 基线

- 设置页“记忆精灵”
- 当前插件清单与配置数量
- 环境事实：shell、PATH、受管 bin
- 保存完整/插件/环境记忆
- 快照时间线、备注、本地持久化

## v0.2.0 — 需求与数据基线

- 冻结需求文档和验收标准
- 统一记忆数据模型与 schemaVersion
- “自上次记忆以来”变更检测
- 完善快照详情
- 明确记忆库正式存储方案

## v0.3.0 — 插件层可恢复

- 恢复前差异预览
- 插件安装/移除/启停/配置恢复
- 恢复前安全记忆
- 失败回退
- 缺包、版本冲突、需要重启的明确报告

## v0.4.0 — 环境记忆

- 环境资产登记：脚本、PATH、非敏感环境变量
- 受管 bin：`$DSH_HOME/memory-sprite/bin`
- 运行时 PATH overlay
- 可选外部终端 profile 代管
- 手动/智能/自动记忆模式

## v0.5.0 — 迁移与救援

- 导出/导入记忆包
- 离线插件包缓存
- 独立救援档案或伴生恢复工具
- 恢复健康检查

## v1.0.0 — 稳定版

- 核心 P0 需求全部验收
- 跨版本兼容策略
- 文档、升级和故障恢复流程完善
